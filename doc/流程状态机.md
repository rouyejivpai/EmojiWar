# EmojiWar2 流程状态机定义（GameFramework 规范）

> 依据：EllanJiang GameFramework（StarForce 范式）——流程继承 `ProcedureBase`，
> 通过 `ProcedureComponent` 的 `m_AvailableProcedureTypeNames`（类型名数组）注册，
> `m_EntranceProcedureTypeName` 指定入口，运行时反射创建，`ChangeState<T>()` 驱动切换。
>
> 代码单一来源：`Assets/GameMain/Scripts/Procedure/ProcedureTypes.cs`
> （改流程先改它；场景 YAML 与 Builder 均引用该常量，避免漂移）。
> 更新时间：2026-08-28

## 2. 状态与转换表

| 状态 | 职责 | 进入（来源） | 离开（去向/触发） |
|---|---|---|---|
| **Launch** | 资源初始化（构建版 `ResourceComponent.InitResources`）、加载数据表 | 启动（入口） | → Menu：资源/数据表就绪后自动 |
| **Menu** | 主菜单 UI（标题/开始按钮） | Launch | → CharacterSelect：点击"开始游戏" |
| **CharacterSelect** | 角色选择 UI（4 角色），写入 `SelectedCharacterId` | Menu | → Lobby：选择角色后 |
| **Lobby** | 大厅 UI（玩家名/IP、创建/加入/返回） | CharacterSelect / GameOver返回菜单 / Room离开 | → Room：创建（Host 模式）或加入（Client 模式）；→ Menu：返回 |
| **Room** | 联机房间 UI（玩家列表/准备/离开），全部准备自动开始 | Lobby / GameOver返回房间 | → Battle：全部玩家准备（Host 广播 `S2CBattleStart`）；→ Lobby：离开/解散/房主退出 |
| **Battle** | 战斗（确定性帧同步模拟 + SimView 渲染），波间商店 UI（Battle 内联打开 ShopForm） | Room | → GameOver：模拟战斗结束（全部玩家死亡，`OnBattleEnded`） |
| **GameOver** | 结算 UI（重新开始/返回菜单） | Battle | → Room：返回房间（Host `ResetRoom` 重置，准备下一局）；→ Menu：返回菜单（解散房间，全员回大厅） |

### 关键守卫条件

- **全部准备才开战**：`NetHostLogic.HandleReadyChange` 检测 `AllReady()`（≥1 人且全部 `Ready=true`）→ 广播 `S2CBattleStart{Seed}` → 各端 `InitializeSimulation(seed)` 重建确定性模拟。
- **Battle 防重复进入**：`ProcedureBattle` 用会话级静态标志 `s_BattleSession`——一局内重复 `ChangeState<Battle>` 直接忽略（防重复开局/场景叠加），玩家死亡进结算或返回菜单才复位。
- **结算后回房**：GameOver"返回房间"→ Host `ResetRoom()`（`ReplayRecorder.End`/`DeterminismTracer.End`、清敌、准备复位、seed=0 房间模拟）→ 全员回 Room 准备下一局。
- **房主退出**：`NetServer` 断开 → Host 广播 `S2CRoomClosed` → 客户端 `RoomClosed()` → 返回 Lobby。

## 3. 数据流（跨流程数据）

| 数据 | 载体 | 说明 |
|---|---|---|
| 角色 ID | `ProcedureBattle.SelectedCharacterId`（静态） | CharacterSelect 写入，Lobby/Room/Battle 读取（构建玩家配置） |
| 玩家名 | `ProcedureLobby.m_PlayerName` | 创建/加入房间时传入 |
| 网络种子 | `S2CBattleStart.Seed` | Host 随机生成广播，各端据此重建确定性模拟 |
| 房间状态 | `S2CPlayerList` / `RoomEvents.PlayerListUpdated` | 房间 UI 实时刷新 |
| 商店商品 | 模拟内确定性生成（同种子同商品），`ShopForm` 直接读模拟 | 不走流程（Battle 内联打开） |

## 5. 维护指引

1. **新增流程**：写 `ProcedureX : ProcedureBase` → 在 `ProcedureTypes.Available` 注册 → （如需）在 `MIGRATION_PLAN.md` 状态机图补转换。
2. **删除流程**：删类 → 从 `Available` 移除 → 场景 YAML 会在下次 Builder 运行时同步（或手动从 Inspector 移除）。
3. **校验**：重跑 `EmojiWar/Setup/02 - Build Room Setup` 会把场景流程列表重置为 `ProcedureTypes.Available` 全量；注意其会覆盖场景当前注册，与手改场景互斥。

## 6. 状态机 ↔ UI 互动定义表（2026-08-28）

> 互动总原则（GF 规范）：
> - **流程 → UI**：`GameEntry.UI.OpenUIForm(资产路径, UIGroup, userData)`（打开）/ `CloseUIForm`（关闭），UI 生命周期归框架管；
> - **UI → 流程**：UIForm 上的**静态事件类**触发（`XxxEvents.RequestXxx()`），流程在 `OnEnter` 订阅、`OnLeave` 退订；
> - **网络 → UI**：`RoomEvents` 事件中心（网络层触发，UI/流程订阅，解耦）；
> - **模拟 → UI**：UI 以**只读轮询**方式从 `GameEntry.SimView`（确定性模拟表现层）读数据（HUD/商店），不反向影响逻辑。

### 6.1 状态 × 界面 × 事件 总表

| 状态 | 关联 UIForm | 打开时机 | 关闭时机 | UI→流程事件（UIForm 触发） | 流程→UI 数据/指令 | 转换去向 |
|---|---|---|---|---|---|---|
| **Launch** | —（无 UI） | — | — | — | — | 资源/数据表就绪 → **Menu** |
| **Menu** | `MenuForm` | `OnEnter`：`OpenUIForm(MenuForm)`（场景已加载则直接开） | `OnLeave`：`UIFormCloser.CloseByName("MenuForm(Clone)")` | `MenuForm.OnStartGameRequested`（点击"开始游戏"） | — | → **CharacterSelect** |
| **CharacterSelect** | `CharacterSelectForm` | `OnEnter`：`OpenUIForm(CharacterSelectForm)` | `OnLeave`：关闭 | `CharacterSelectEvents.OnCharacterSelected(int id)`（4 角色按钮） | 选中 id → 写 `ProcedureBattle.SelectedCharacterId` | → **Lobby** |
| **Lobby** | `LobbyForm` | `OnEnter`：`OpenUIForm(LobbyForm)` | `OnLeave`：关闭 | `LobbyForm.OnCreateRoomRequested(string 名)` / `OnJoinRoomRequested(string 名,string IP,int 端口)` / `OnBackRequested` | 创建→`NetworkService.StartHost()`+`JoinLocal`；加入→`ConnectToServer`+`JoinRoom`；返回→`Shutdown`+`LeaveRoom` | → **Room** / → **Menu** |
| **Room** | `RoomForm` | `OnEnter`：`OpenUIForm(RoomForm)` | `OnLeave`/`OnRoomClosed`：关闭 | `RoomFormEvents.OnReadyRequested`（准备按钮） / `OnLeaveRequested`（离开按钮） | 准备→Host `SetLocalReady` / Client `SendReady`；离开→`Shutdown`+`LeaveRoom`；**网络→UI**：`RoomEvents.PlayerListUpdated`（列表刷新）、`RoomEvents.LocalReadyChanged`（按钮状态） | → **Battle**（全部准备）/ → **Lobby** |
| **Battle** | `BattleHudForm` + `ShopForm`（波间） | `OnEnter`：`OpenUIForm(BattleHudForm)`；`OnShopPhase(wave)` 事件 → `OpenUIForm(ShopForm)` | `OnLeave`/重开：`CloseBattleForms()` | 商店购买→`NetClientLogic.RequestBuy(i)` / Host `HandleBuyItem`（走网络，不经 UI 事件） | **模拟→UI（轮询）**：HUD 每 0.2s 从 `SimView.GetLocalPlayer()` 读 HP/武器/弹药/波次/金币；ShopForm 直接读模拟商店商品（确定性生成） | → **GameOver**（玩家死亡/战斗结束） |
| **GameOver** | `GameOverForm` | `OnEnter`：`OpenUIForm(GameOverForm)` | `OnLeave`：关闭 | `GameOverEvents.OnRestartRequested`（返回房间）/ `OnMenuRequested`（返回菜单） | 返回房间→Host `ResetRoom()`（清敌/准备复位/seed=0）再回 Room；返回菜单→`Shutdown`+`LeaveRoom`+回 Menu | → **Room** / → **Menu** |

### 6.3 数据流方向总结

```
┌─────────────┐   OpenUIForm/CloseUIForm   ┌──────────────────┐
│ Procedure   │ ─────────────────────────▶ │  UIForm（框架管） │
│ （状态机）    │ ◀───────────────────────── │                  │
└─────────────┘   静态事件类（XxxEvents）    └──────────────────┘
      │  ▲                                      │  ▲
      │  │ ChangeState<T>()                      │  │ 轮询只读
      ▼  │                                      ▼  │
┌─────────────┐  RoomEvents（网络→UI 事件中心）  ┌──────────────┐
│  网络层       │ ─────────────────────────────▶ │  确定性模拟    │
│ NetHost/     │                                │ SimView      │
│ NetClient    │ ◀──── C2S 意图/请求 ─────────── │ LockstepSim  │
└─────────────┘                                └──────────────┘
```

- **UI 不直接碰逻辑**：HUD/商店通过 `GameEntry.SimView` 只读快照；所有状态变更（准备/购买/离开）都经事件 → 流程 → 网络/模拟，符合"UI 只响应数据变化"原则。
- **测试入口**：`TriggerStartGame/TriggerCreateRoom/TriggerJoinRoom/RequestReady/RequestRestart` 等静态方法供 `AutoPlay`（-autocreate/-autojoin）自动化驱动，无需手工点 UI。
